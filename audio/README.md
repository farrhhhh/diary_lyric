# Audio Files

Place your `.mp3` trigger audio clips here:

| Filename        | Trigger Word |
|-----------------|-------------|
| whenever.mp3    | whenever    |
| love.mp3        | love        |
| alone.mp3       | alone       |
| baby.mp3        | baby        |
| money.mp3       | money       |

**Note:** Use short clips (5–15 seconds) for best comedic effect.
If a file is missing, the app will show a funny fallback message instead of crashing.
